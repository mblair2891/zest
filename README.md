# Zest

Hospitality OS for restaurants, food halls, and truck pods.

## Fresh start

The app starts **empty** — no demo tenants, menus, or staff.

Default platform admin (change immediately):

- Username: `Admin`
- Initial password: `password`
- First login **requires** a password change before SaaS or POS.

Details: [`docs/empty-start.md`](docs/empty-start.md).
